Apa itu QuickSort?

QuickSort adalah algoritma pengurutan berbasis Divide and Conquer yang memilih satu elemen sebagai pivot lalu membagi array menjadi dua bagian: elemen lebih kecil dari pivot di kiri, dan elemen lebih besar di kanan.

Konsep Dasar (Pivot)

Pivot adalah elemen kunci pembanding. Semua elemen lebih kecil dari pivot dipindahkan ke kiri, dan elemen lebih besar ke kanan. Proses ini disebut partisi, lalu diulang secara rekursif.

Cara Kerja

1. Pilih pivot (elemen terakhir — Lomuto).
2. Partisi array: kiri < pivot, kanan > pivot.
3. Tempatkan pivot di posisi akhirnya.
4. Rekursi pada sub-array kiri dan kanan.

▸ Pseudocode QuickSort (Lomuto)
quickSort(arr, low, high): if low < high: p = partition(arr, low, high) // tempatkan pivot quickSort(arr, low, p - 1) // rekursi kiri quickSort(arr, p + 1, high) // rekursi kanan partition(arr, low, high): pivot = arr[high] // pivot = elemen terakhir i = low - 1 for j = low to high - 1: if arr[j] <= pivot: i++ swap(arr[i], arr[j]) // pindahkan ke kiri swap(arr[i+1], arr[high]) // tempatkan pivot return i + 1
